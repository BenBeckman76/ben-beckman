Case Study

Deep dive into a recent Project

football tactics Board

A browserbased tool for building and sharing football game plans for coaches, analysts, and fans. Start from a preset formation, then drag players and the ball around the pitch and sketch tactics with line, arrow, pen, and highlight tools. Players can be relabeled, substitutes brought on, and moves animated frame by frame, all with undo/redo. Boards save under named slots, export as PNG, or share instantly via a single link no account needed. Built with plain HTML, CSS, and JavaScript, keeping it fast and lightweight.

The Problem

Explaining football tactics usually means static diagrams or whiteboard photos that can't show movement or be easily edited and shared

My Approach

Plan to build it with vanilla HTML, CSS, and JavaScript no frameworks needed. Player and ball positions will live in a simple JS state object, rendered as draggable elements on a percentage-based pitch. Drawings will use an HTML canvas layered on top. State will save to localStorage, with sharing handled by encoding it into a URL link.

What I'd Improve Next

Future plans include true pinch-to-zoom on mobile, a proper backend so tactics can be shared across devices (not just via URL), and cloud accounts instead of localStorage.
